# 서진메디텍 의료기기 랜딩페이지 프로토타입

정적 HTML/CSS/JavaScript로 제작한 전환 중심 랜딩페이지입니다.

## 실행

`index.html`을 직접 열거나 로컬 정적 서버로 확인합니다.

## 게시 전 반드시 교체·확인할 항목

- 실제 대표 연락처와 문의 전송 방식
- 회사명, 대표자, 사업자등록번호, 주소 등 푸터 정보
- 실제 취급 제품 이미지와 공식 제품명
- 제품 사양, 의료기기 허가사항, 수가·효과·수익성 관련 문구의 근거
- 개인정보 처리방침의 수집 주체, 보유 기간, 처리 위탁 범위

현재 폼은 데모이며 외부로 데이터를 전송하지 않습니다.
